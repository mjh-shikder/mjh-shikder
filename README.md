## 👨‍💻 About Me

I'm a MERN-stack developer who enjoys turning real-world workflows into reliable, well-structured web apps. My recent work spans a **full-stack property rental platform** (Next.js + Express + Prisma + Stripe) and a **healthcare appointment API** that I'm actively building out.

I care about:

- **Clean architecture:** separating concerns between frontend, API, and data layers
- **Role-based experiences:** tailoring dashboards and permissions to each type of user
- **Secure, practical features:** JWT authentication, payments, and validated data flows

## 🚀 Featured Projects

### 🏠 [RentNest: Property Rental Platform](https://github.com/mjh-shikder/A05-Level-2-RentNest_Frontend)

A full-stack rental marketplace connecting **tenants, landlords, and administrators**.

- Browse, search, filter, and sort property listings
- Role-based dashboards for tenant, landlord, and admin workflows
- Rental requests, landlord approval/rejection, payment history, and reviews
- **Stripe Checkout** integration for approved rental requests
- Next.js App Router frontend connected to an Express + Prisma REST API

**Stack:** `Next.js` `React` `TypeScript` `Tailwind CSS` `Express.js` `Prisma` `PostgreSQL` `Stripe`

[🔗 Live App](https://rentnest.mjhshikder.com/) · [💻 Frontend](https://github.com/mjh-shikder/A05-Level-2-RentNest_Frontend) · [⚙️ Backend](https://github.com/mjh-shikder/A04-Level-2-Rent_Nest_Backend) · [🎥 Walkthrough](https://www.loom.com/share/5c66e15a92dd4d60bc4574e0dfd306dc)
